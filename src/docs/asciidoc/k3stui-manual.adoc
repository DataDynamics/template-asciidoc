== 이 매뉴얼에 대하여

이 문서는 공개 프로젝트 {repo-url}[K3s & K8s Management TUI ({tool})] 의 README 와 설정 파일을 바탕으로
만든 *매뉴얼 샘플* 입니다. 화면 그림도 같은 저장소의 스크린샷을 사용했습니다.
{tool} 은(는) Apache License 2.0 으로 배포됩니다.

다른 샘플인 "Lumen 지식 검색" 매뉴얼이 여러 부(part)로 나눈 큰 매뉴얼이라면,
이 문서는 부 없이 장(chapter)만으로 구성한 *한 권짜리 매뉴얼* 의 예입니다.

* 장 파일은 `k3stui/` 디렉터리에 둡니다.
* 키 입력은 `+kbd:[Ctrl+R]+` 처럼 kbd 매크로로, 화면 그림은 `images/k3stui/` 에 둡니다.
* 키 참조와 문제 해결처럼 찾아보는 내용은 부록으로 뺍니다.

NOTE: 기능과 옵션은 {tool} 버전에 따라 달라질 수 있습니다. 최신 내용은 {repo-url}[프로젝트 저장소]를 확인하십시오.
