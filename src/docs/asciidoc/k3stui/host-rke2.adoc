[[k3stui-host-rke2]]
== 노드 관리: RKE2

RKE2 서버 노드에서 root 로 실행하면 Host 탭이 K3s 와 같은 하위 탭으로 구성됩니다(<<k3stui-host-k3s>>).
다른 점은 다음과 같습니다.

[cols="1,3", options="header"]
|===
| 항목 | RKE2 에서의 동작

| 서비스 | `rke2-server` 또는 `rke2-agent`. `rke2.service_name: auto` 는 실행 중인 유닛을 고릅니다
| 실행 파일 | `/usr/local/bin/rke2` → `/usr/bin/rke2` → `/opt/rke2/bin/rke2` 순으로 찾습니다
| 설정 | `/etc/rancher/rke2/config.yaml`(+ `config.yaml.d`) 보기·편집
| 인증서 | kbd:[R] 은 서비스 중지 → `rke2 certificate rotate` → 시작 순으로 갱신합니다
| 백업 | `rke2 etcd-snapshot save` 로 etcd 스냅샷을 만듭니다. kbd:[R] 은 `rke2 server --cluster-reset` 복원 절차를 보여 줍니다
| 노드 추가 명령 | agent 설치, `config.yaml` 작성(`server: https://<서버>:9345` 와 토큰), `rke2-agent` 시작까지 한 번에 보여 줍니다
|===

NOTE: RKE2 에는 `check-config` 명령과 SQLite 데이터스토어가 없어서 서비스 화면의 kbd:[c] 키와 자동 복원은 나오지 않습니다.
