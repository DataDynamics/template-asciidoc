[[k3stui-overview]]
== 개요

{tool} 은(는) K3s 와 Kubernetes(K8s) 클러스터를 터미널 하나에서 관리하는 TUI 입니다.

k9s 처럼 Pod, Deployment, Service 같은 *Kubernetes 리소스* 를 다루는 데 그치지 않고,
일반 도구가 다루지 않는 *노드(호스트) 관리* 까지 한 화면에서 합니다.
서비스 제어와 로그, 설정 파일 편집, 데이터스토어 백업, 인증서 갱신, 노드 추가 명령,
containerd 이미지·컨테이너 정리를 TUI 안에서 처리할 수 있습니다.

[[k3stui-overview-distributions]]
=== 지원 배포판

{tool} 은(는) 실행한 노드의 배포판을 자동으로 판별해 노드 관리 기능을 구성합니다.

.배포판별 지원 범위
[cols="1,1,3", options="header"]
|===
| 배포판 | 리소스 관리 | 노드 관리 (Host 탭)

| K3s | 지원 | k3s 서비스, `config.yaml`, 자동 배포 manifest, SQLite·etcd 백업과 SQLite 복원, 인증서 갱신, 노드 추가 명령
| RKE2 | 지원 | rke2-server/agent 서비스, `config.yaml`, 자동 배포 manifest, etcd 스냅샷, 인증서 갱신, 노드 추가 명령
| kubeadm | 지원 | kubelet 서비스와 설정, static Pod 편집, PKI 인증서 갱신, etcd 스냅샷, 노드 추가 토큰
| 그 밖의 Kubernetes (EKS·GKE·AKS 등, 원격 클러스터) | 지원 | 없음
|===

노드 관리는 API 서버가 있는 노드에서 실행할 때 켜지며, 서비스 제어·편집·백업 같은 변경 작업에는 root 권한이 필요합니다.
원격 클러스터에 붙는 방법은 <<k3stui-other-clusters>> 를 참고하십시오.

[[k3stui-overview-features]]
=== 주요 기능

[cols="1,4", options="header"]
|===
| 영역 | 기능

| 대시보드 | 클러스터 요약, 노드별 CPU·메모리·Pod 게이지, 서비스 상태, 데이터스토어 크기, 가장 빠른 인증서 만료일, 디스크 사용률, 문제 Pod, 최근 Warning 이벤트
| 리소스 | Pod·Deployment·StatefulSet·DaemonSet·Job·CronJob·Service·Ingress·PVC·ConfigMap·Secret·RBAC 등 조회, 실시간 갱신(watch), 필터, 네임스페이스 전환
| 리소스 작업 | describe, YAML 보기, `$EDITOR` 로 편집, 삭제, 로그(follow), 컨테이너 셸, 포트포워딩, 스케일, 롤아웃 재시작, CronJob 즉시 실행, 노드 cordon·drain
| 노드 서비스 | 상태·가동 시간·메모리 확인, 시작·중지·재시작, `journalctl` 로그 스트림, 노드 추가 명령 생성
| 설정 | 노드 `config.yaml` 보기·편집 (YAML 검증 → 변경 비교 → 백업 후 저장 → 재시작 질의)
| 데이터스토어 | SQLite 온라인 백업, 보관 개수 관리, 복원(무결성·토큰 검사 포함), etcd 스냅샷
| 기타 | 자동 배포 manifest `.skip` 전환, 인증서 만료 확인·갱신, containerd 이미지 정리, Helm 릴리스(values·이력·롤백·삭제), Cilium 에이전트 상태
|===
