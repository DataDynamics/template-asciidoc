== 용어 정리

[horizontal]
지식베이스:: 문서를 주제별로 묶은 단위. 검색과 권한의 경계입니다.
조각:: 검색 단위로 나눈 문서의 일부. 검색 결과는 조각 단위로 나옵니다.
색인:: 문서를 빠르게 찾을 수 있도록 미리 정리해 둔 자료 구조.
재색인:: 설정을 바꾼 뒤 문서를 처음부터 다시 색인하는 일.
의미 검색:: 단어가 달라도 뜻이 비슷한 내용을 찾는 검색.
혼합 검색:: 키워드 검색과 의미 검색의 결과를 합친 검색.
커넥터:: 외부 저장소의 문서를 가져오는 연결.
배분 규칙:: 새 문서를 어느 지식베이스에 넣을지 정하는 규칙.
확신도:: 자동 배분 결과가 맞을 가능성을 0~1 로 나타낸 값.
