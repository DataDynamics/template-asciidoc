== 문제 해결

.증상별 점검 순서
[cols="1,2,2", options="header"]
|===
| 증상 | 확인할 것 | 조치

| 문서를 올렸는데 검색되지 않음
| 문서 상태(<<kb-upload-status>>), 색인 노드 상태(<<services-nodes-status>>)
| *실패* 면 다시 처리, *대기* 가 길면 색인 노드 확인

| 문서 처리 실패: "암호화된 파일"
| 파일에 열기 암호가 걸려 있는지
| 암호를 풀고 다시 올리기

| 문서 처리 실패: "글자를 찾을 수 없음"
| 스캔한 이미지 PDF 인지
| 지식베이스 설정에서 글자 인식(OCR)을 켜고 다시 처리

| 검색 결과가 엉뚱함
| 분할 방식, 동의어, 가중치
| <<kb-segmentation>>, <<tuning-synonyms>>, <<tuning-boosting>> 검토 후 <<quality-evaluation>> 으로 확인

| 문서가 엉뚱한 지식베이스에 들어감
| 규칙 순서와 시험 결과
| <<routing-rules-test>> 로 원인 규칙을 찾고 순서 조정

| API 호출이 `401` 로 실패
| API 키 만료·폐기 여부
| 새 키 발급(<<ops-api-keys-issue>>)
|===
