[[journey]]
== 사용 여정 한눈에 보기

이 매뉴얼은 {product-short} 을(를) 처음 도입해 운영하기까지의 순서대로 구성되어 있습니다.
이미 구축이 끝난 환경의 일반 사용자는 <<search>> 부터 읽어도 됩니다.

.부별 내용과 대상 독자
[cols="1,3,1", options="header"]
|===
| 부 | 내용 | 대상

| 1부 시작하기 | 체험용 환경에서 지식베이스를 만들고 첫 검색까지 해 봅니다. | 모든 사용자
| 2부 설치·구축 | 요구 사항을 확인하고 운영 환경에 설치합니다. | 시스템 관리자
| 3부 서비스 준비 | 색인 노드와 외부 저장소 커넥터를 연결합니다. | 시스템 관리자
| 4부 지식베이스 구축 | 지식베이스를 만들고 문서를 넣습니다. | 지식 관리자
| 5부 문서 자동 배분 | 새 문서를 규칙으로 알맞은 지식베이스에 보냅니다. | 지식 관리자
| 6부 검색·질의 | 검색 화면과 어시스턴트를 사용합니다. | 일반 사용자
| 7부 품질 관리 | 검색 품질을 측정하고 피드백으로 개선합니다. | 지식 관리자
| 8부 검색 튜닝 | 동의어와 가중치로 검색 결과를 다듬습니다. | 지식 관리자
| 9부 운영 관리 | 사용자, API 키, 모니터링, 백업을 관리합니다. | 시스템 관리자
|===

[[journey-roles]]
=== 역할별 추천 경로

시스템 관리자:: 2부 → 3부 → <<ops-users>> → <<kb-create>> 까지 진행한 뒤 지식 관리자에게 넘깁니다.
지식 관리자:: 4부 → 5부 → 7부 → 8부 순서로 읽습니다.
일반 사용자:: <<search>> 와 <<assistant>> 두 장이면 충분합니다.
