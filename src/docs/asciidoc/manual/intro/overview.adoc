[[overview]]
== 개요

{product} 은(는) 사내에 흩어진 문서를 한곳에 모아 *키워드 검색* 과 *의미 검색* 으로 찾고,
찾은 문서를 근거로 질문에 답하는 *검색 어시스턴트* 를 제공하는 가상의 제품입니다.

[[overview-features]]
=== 주요 기능

[cols="1,3", options="header"]
|===
| 기능 | 설명

| 지식베이스
| 문서를 주제별 묶음(지식베이스)으로 관리합니다. 지식베이스마다 접근 권한과 검색 설정을 따로 둡니다.

| 문서 수집
| 파일 업로드, 공유 폴더 연결, 커넥터로 문서를 모읍니다. 수집한 문서는 자동으로 색인됩니다.

| 자동 배분
| 규칙에 따라 새 문서를 알맞은 지식베이스로 보냅니다. 확신이 낮은 결정은 사람이 검토합니다.

| 검색·어시스턴트
| 키워드와 의미를 함께 쓰는 검색, 출처를 밝히는 대화형 어시스턴트를 제공합니다.

| 품질 관리
| 평가 질문 세트로 검색 품질을 측정하고, 사용자 피드백을 모아 개선합니다.

| 운영 관리
| 사용자·권한, API 키, 모니터링, 백업을 관리합니다.
|===

=== 구성 요소

.{product} 구성
image::lumen-architecture.svg[{product} 구성도,640]

* *웹 콘솔* — 사용자와 관리자가 쓰는 화면입니다. 기본 주소는 `{console-url}` 입니다.
* *API 서버* — 검색, 수집, 관리 기능을 REST API 로 제공합니다(포트 {api-port}).
* *색인 노드* — 문서를 분석하고 검색 색인을 만듭니다. 문서량에 따라 여러 대로 늘립니다.
* *저장소* — 원본 문서와 색인, 설정을 보관합니다.
