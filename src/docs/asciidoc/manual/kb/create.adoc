[[kb-create]]
== 지식베이스 만들기

지식베이스는 문서를 묶는 단위이자 검색과 권한의 경계입니다.
예를 들어 `인사 규정`, `제품 기술 문서`, `고객 FAQ` 처럼 주제나 독자가 다른 문서는 지식베이스를 나눕니다.

[[kb-create-dialog]]
=== 만들기 화면

.지식베이스 설정 항목
[cols="1,3,1", options="header"]
|===
| 항목 | 설명 | 나중에 변경

| 이름 | 목록과 검색 필터에 표시되는 이름입니다. | 가능
| 설명 | 지식베이스의 용도. 자동 배분의 판단 근거로도 쓰입니다(<<routing-rules>>). | 가능
| 공개 범위 | 전체 공개 / 특정 그룹 / 비공개 | 가능
| 문서 언어 | 주 언어. 형태소 분석 방식이 달라집니다. | 재색인 필요
| 분할 방식 | 문서를 검색 단위로 나누는 방식(<<kb-segmentation>>). | 재색인 필요
|===

WARNING: *재색인 필요* 항목을 바꾸면 지식베이스의 모든 문서를 다시 색인합니다.
문서가 많으면 몇 시간 걸릴 수 있으니 업무 시간을 피해 바꾸십시오.
