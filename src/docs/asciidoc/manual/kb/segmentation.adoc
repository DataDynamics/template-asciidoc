[[kb-segmentation]]
== 문서 분할 방식

긴 문서는 검색 단위인 *조각* 으로 나눠 색인합니다. 조각이 너무 크면 엉뚱한 부분까지 함께 걸리고,
너무 작으면 앞뒤 맥락이 끊깁니다.

.분할 방식 (예시)
[cols="1,2,2", options="header"]
|===
| 방식 | 동작 | 어울리는 문서

| 자동 (기본) | 제목 구조가 있으면 제목 단위, 없으면 문단 단위로 나눕니다. | 대부분의 문서
| 제목 단위 | 장·절 제목을 경계로 나눕니다. | 규정, 매뉴얼
| 문단 단위 | 빈 줄을 경계로 나눕니다. | 보고서, 공지
| 질문·답변 | `Q.` / `A.` 쌍을 한 조각으로 묶습니다. | FAQ
|===

[[kb-segmentation-example]]
=== 예: 제목 단위 분할

[source,text]
.입력 문서
----
제3장 휴가
 제10조 연차휴가  연차는 입사 1년 후 15일이 주어진다 ...
 제11조 병가      병가는 연 30일 이내로 ...
----

제목 단위로 나누면 `제10조 연차휴가` 와 `제11조 병가` 가 각각 한 조각이 되고,
각 조각에는 `제3장 휴가 > 제10조 연차휴가` 같은 *위치 정보* 가 붙어 검색 결과에 표시됩니다.

TIP: 분할 방식을 고르기 어렵다면 *자동* 으로 시작하고, <<quality-evaluation>> 결과를 보며 바꾸십시오.
