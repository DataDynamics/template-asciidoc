[[kb-upload]]
== 문서 넣기

[[kb-upload-ways]]
=== 넣는 방법

화면에서 올리기:: 지식베이스 화면에서 btn:[문서 올리기]를 누르거나 파일을 끌어다 놓습니다. 한 번에 100개까지 올릴 수 있습니다.
커넥터로 가져오기:: <<services-connectors>> 에 등록한 저장소에서 주기적으로 가져옵니다.
API 로 넣기:: 다른 시스템에서 `POST /documents` 를 호출합니다(<<appendix-api>>).

[[kb-upload-formats]]
=== 지원 형식

* 문서: PDF, DOCX, PPTX, XLSX, HWP, HWPX
* 텍스트: TXT, Markdown, HTML, CSV
* 이미지 속 글자는 PDF 와 이미지 파일에 한해 자동으로 인식합니다(OCR).

[[kb-upload-status]]
=== 처리 상태

올린 문서는 다음 상태를 거쳐 검색할 수 있게 됩니다.

[cols="1,3", options="header"]
|===
| 상태 | 의미

| 대기 | 색인 노드가 작업을 가져가기를 기다립니다.
| 분석 중 | 글자를 추출하고 검색 단위로 나눕니다.
| 색인 완료 | 검색할 수 있습니다.
| 실패 | 오류 내용을 확인하고 btn:[다시 처리]를 누릅니다. 원인은 <<appendix-troubleshooting>> 를 참고하십시오.
|===

NOTE: 내용이 같은 파일을 다시 올리면 중복으로 판단해 건너뜁니다.
