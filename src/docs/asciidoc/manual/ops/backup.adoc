[[ops-backup]]
== 백업과 복구

[[ops-backup-what]]
=== 백업 대상

* 저장소 볼륨(`lumen-data`) — 원본 문서, 색인, 사용자·설정 정보가 모두 들어 있습니다.
* 설정 파일 `lumen.yml`

[[ops-backup-run]]
=== 백업

[source,console]
----
$ docker compose exec lumen-store lumen-backup --output /var/lib/lumen/backup/   # <1>
$ ls lumen-data/backup/                                                           # <2>
----
<1> 서비스를 멈추지 않고 일관된 백업을 만듭니다.
<2> 날짜가 이름에 붙은 백업 파일이 생깁니다. 다른 서버나 저장소로 복사해 두십시오.

[[ops-backup-restore]]
=== 복구

. 모든 서비스를 멈춥니다: `docker compose stop`
. 백업 파일로 복구합니다: `docker compose run --rm lumen-store lumen-restore <백업 파일>`
. 서비스를 다시 시작하고 검색이 되는지 확인합니다.

CAUTION: 복구하면 백업 이후에 추가한 문서와 설정은 사라집니다. 커넥터로 가져온 문서는 다음 동기화 때 다시 들어옵니다.
