[[ops-users]]
== 사용자와 권한

화면: menu:관리[사용자].

[[ops-users-roles]]
=== 역할

.기본 역할
[cols="1,3", options="header"]
|===
| 역할 | 할 수 있는 일

| 관리자 | 모든 기능. 사용자, API 키, 설정 관리
| 지식 관리자 | 맡은 지식베이스의 문서·규칙·튜닝 관리, 품질 관리
| 사용자 | 볼 권한이 있는 지식베이스의 검색과 어시스턴트
|===

[[ops-users-groups]]
=== 그룹과 지식베이스 권한

사용자를 그룹(예: `인사팀`, `영업본부`)으로 묶고, 지식베이스의 공개 범위를 그룹 단위로 지정합니다.
조직 계정(SSO)을 쓰면 조직의 그룹 정보를 그대로 가져올 수 있습니다(<<install-config>> 의 `auth` 항목).

TIP: 사용자마다 권한을 주기보다 그룹에 권한을 주십시오. 인사 이동 때 그룹만 바꾸면 됩니다.
