[[quality-evaluation]]
== 검색 품질 평가

설정을 바꿀 때마다 감으로 판단하지 않도록, *평가 질문 세트* 로 검색 품질을 숫자로 측정합니다.
화면: menu:품질 관리[평가].

[[quality-evaluation-set]]
=== 평가 질문 세트

평가 질문 세트는 "이 질문이면 이 문서가 나와야 한다" 는 쌍의 모음입니다.

[source,csv]
.평가 질문 세트 예 (CSV 로 가져오기)
----
질문,정답 문서
입사 2년 차 연차 일수는?,인사규정.pdf
출장비 정산 기한은?,출장 지침.docx
----

TIP: 질문은 실제 사용자가 묻는 말투로 쓰십시오. 질문 수는 50개 이상을 권장합니다.

[[quality-evaluation-metrics]]
=== 지표

.평가 지표
[cols="1,3", options="header"]
|===
| 지표 | 의미

| 적중률 | 정답 문서가 상위 5개 결과 안에 든 질문의 비율. 높을수록 좋습니다.
| 평균 순위 | 정답 문서가 나온 평균 순위. 낮을수록 좋습니다.
| 답변 근거율 | 어시스턴트 답변이 근거 문서 내용과 일치한 비율.
|===

[[quality-evaluation-compare]]
=== 설정 비교

평가를 실행하면 결과가 기록으로 남습니다. 설정을 바꾸기 전과 후의 기록을 나란히 놓고 지표를 비교하십시오.
지표가 나빠졌다면 설정을 되돌립니다.
