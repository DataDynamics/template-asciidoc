[[quality-feedback]]
== 사용자 피드백

사용자가 검색 결과와 어시스턴트 답변에 남긴 btn:[좋아요] / btn:[아쉬워요] 를 모아 품질 개선에 씁니다.
화면: menu:품질 관리[피드백].

[[quality-feedback-handle]]
=== 피드백 처리

. btn:[아쉬워요] 피드백을 엽니다. 질문, 답변, 사용자가 남긴 의견이 표시됩니다.
. 원인을 판단합니다.
  * 문서가 없음 → 지식베이스에 문서를 추가합니다.
  * 문서는 있지만 순위가 낮음 → <<tuning-synonyms>> 나 <<tuning-boosting>> 을 검토합니다.
  * 답변이 부정확함 → 근거 문서 내용이 최신인지 확인합니다.
. btn:[평가 세트에 추가]를 누르면 이 질문이 <<quality-evaluation>> 의 질문 세트에 들어갑니다.
  같은 문제가 다시 생기는지 계속 확인할 수 있습니다.
