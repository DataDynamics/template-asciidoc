[[routing-review]]
== 검토 대기

확신도가 기준보다 낮은 배분과 미분류 문서는 *검토 대기* 목록에 쌓입니다.
화면: menu:자동 배분[검토 대기].

[[routing-review-actions]]
=== 처리 방법

[cols="1,3", options="header"]
|===
| 동작 | 결과

| btn:[맞음] | 자동 배분 결과를 그대로 확정합니다.
| btn:[옮기기] | 다른 지식베이스를 골라 옮깁니다. 옮긴 문서는 새 지식베이스 설정으로 다시 색인됩니다.
| btn:[제외] | 검색 대상에서 뺍니다. 원본은 지우지 않습니다.
|===

[[routing-review-suggest]]
=== 규칙 제안

같은 종류의 문서를 같은 지식베이스로 여러 번 옮기면, 화면 아래에 *규칙 제안* 이 나타납니다.

====
*제안 예:* 파일 이름에 `견적서` 가 들어간 문서를 `영업 자료` 로 5번 옮겼습니다.
"파일 이름에 `견적서` 포함 → `영업 자료`" 규칙을 추가할까요?
====

btn:[규칙에 추가]를 누르면 <<routing-rules>> 에 규칙이 추가되고, 이후 같은 문서는 자동으로 배분됩니다.

TIP: 검토 대기가 계속 쌓인다면 규칙이 부족하다는 신호입니다. 규칙 제안을 적극적으로 활용하십시오.
