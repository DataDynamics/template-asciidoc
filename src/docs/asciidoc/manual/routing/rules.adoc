[[routing-rules]]
== 배분 규칙

문서가 여러 곳에서 계속 들어오면 담당자가 일일이 지식베이스를 고르기 어렵습니다.
*배분 규칙* 을 만들어 두면 새 문서를 알맞은 지식베이스로 자동으로 보냅니다.
화면: menu:자동 배분[규칙].

[[routing-rules-types]]
=== 규칙 종류

규칙은 위에서부터 차례로 검사하고, 처음 맞는 규칙을 따릅니다.
비용이 적고 확실한 규칙을 위에, 판단이 필요한 규칙을 아래에 둡니다.

.규칙 종류 (예시)
[cols="1,2,2", options="header"]
|===
| 종류 | 조건 예 | 특징

| 폴더 경로 | `/공유/인사/**` | 가장 정확합니다. 폴더 규칙을 먼저 정해 두면 좋습니다.
| 파일 이름 | 이름에 `계약서` 포함 | 이름 짓기 규칙이 있는 조직에 유용합니다.
| 문서 속성 | 작성 부서 = `재무팀` | 문서에 속성이 들어 있어야 합니다.
| 내용 유사도 | 지식베이스 설명과 비슷한 정도 | 규칙이 없는 문서를 받아 줍니다. 확신도가 함께 나옵니다.
|===

[[routing-rules-fallback]]
=== 미분류 보관함

어떤 규칙에도 맞지 않는 문서는 *미분류* 보관함으로 갑니다.
미분류 문서는 검색되지 않으므로 <<routing-review>> 에서 주기적으로 정리하십시오.

[[routing-rules-test]]
=== 규칙 시험

btn:[시험하기]에 파일 이름이나 경로를 넣으면 저장하지 않고 어느 지식베이스로 갈지 미리 볼 수 있습니다.
규칙을 바꾸기 전과 후에 같은 예시로 시험해 결과를 비교하십시오.
