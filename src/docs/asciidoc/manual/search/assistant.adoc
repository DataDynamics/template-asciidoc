[[assistant]]
== 어시스턴트

어시스턴트는 검색한 문서를 근거로 질문에 답합니다. 답변의 각 문장에는 근거 문서 번호가 붙습니다.

[[assistant-use]]
=== 사용 방법

. 검색 화면 오른쪽의 *어시스턴트* 패널을 엽니다.
. 질문을 문장으로 입력합니다. 예: `입사 2년 차의 연차 일수는?`
. 답변의 `[1]`, `[2]` 번호를 누르면 근거 문서의 해당 위치가 열립니다.
. 이어서 질문하면 앞의 대화 맥락을 이어 답합니다. 새 주제는 btn:[새 대화]로 시작하십시오.

[[assistant-limits]]
=== 알아 둘 점

* 근거 문서를 찾지 못하면 "관련 문서를 찾지 못했습니다" 라고 답합니다. 지어내지 않습니다.
* 답변은 문서 내용을 요약한 것입니다. 중요한 결정은 근거 문서를 직접 확인하십시오.
* 답변 아래의 btn:[좋아요] / btn:[아쉬워요] 로 평가를 남기면 <<quality-feedback>> 에 모입니다.

CAUTION: 개인 정보나 기밀 정보를 질문에 넣지 마십시오. 대화 기록은 품질 개선을 위해 일정 기간 보관됩니다.
