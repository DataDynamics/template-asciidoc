[[search]]
== 검색

[[search-modes]]
=== 검색 방식

[cols="1,3", options="header"]
|===
| 방식 | 설명

| 키워드 | 입력한 단어가 들어 있는 조각을 찾습니다. 제품 코드, 조항 번호처럼 정확한 표현에 강합니다.
| 의미 | 뜻이 비슷한 조각을 찾습니다. "휴가" 로 찾아도 "연차" 가 나옵니다.
| 혼합 (기본) | 두 방식의 결과를 합쳐 순위를 매깁니다. 대부분의 경우 가장 좋은 결과를 냅니다.
|===

[[search-syntax]]
=== 검색어 문법

.검색어 문법
[cols="1,2,2", options="header"]
|===
| 문법 | 예 | 의미

| `"…"` | `"연차 휴가"` | 구절이 그대로 들어 있는 문서
| `-` | `휴가 -병가` | `병가` 가 들어간 문서는 빼기
| `kb:` | `kb:인사규정 휴가` | 특정 지식베이스에서만 찾기
| `type:` | `type:pdf 견적` | 특정 형식의 문서만 찾기
|===

[[search-results]]
=== 결과 화면

* 결과마다 문서 제목, 위치 정보(예: `제3장 휴가 > 제10조`), 일치 구간이 표시됩니다.
* 문서 제목을 누르면 원본의 해당 위치가 열립니다.
* 왼쪽 필터로 지식베이스, 형식, 수정 날짜를 좁힐 수 있습니다.

NOTE: 검색 결과에는 내가 볼 권한이 있는 지식베이스의 문서만 나옵니다.
