[[services-connectors]]
== 외부 저장소 커넥터

커넥터는 공유 폴더나 클라우드 저장소의 문서를 {product-short} 로 가져옵니다.
화면: menu:관리[커넥터].

.지원 커넥터 (예시)
[cols="1,2,2", options="header"]
|===
| 종류 | 연결 정보 | 비고

| 공유 폴더 | 서버 경로, 계정 | 읽기 권한만 있으면 됩니다.
| S3 호환 저장소 | 엔드포인트, 버킷, 접근 키 | 접두사로 범위를 좁힐 수 있습니다.
| 위키 | 사이트 주소, API 토큰 | 페이지와 첨부 파일을 함께 가져옵니다.
|===

[[services-connectors-add]]
=== 커넥터 등록

. btn:[커넥터 추가]를 누르고 종류를 선택합니다.
. 연결 정보를 입력하고 btn:[연결 테스트]를 누릅니다.
. 테스트가 성공하면 *가져오기 주기*(예: 1시간마다)를 정하고 저장합니다.

IMPORTANT: {product-short} 은(는) 커넥터로 연결한 원본을 수정하거나 지우지 않습니다. 원본에서 지운 문서는 다음 동기화 때 검색에서 빠집니다.

커넥터로 들어온 문서를 어느 지식베이스에 넣을지는 <<routing-rules>> 로 정합니다.
