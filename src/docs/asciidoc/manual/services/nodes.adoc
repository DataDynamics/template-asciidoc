[[services-nodes]]
== 색인 노드 관리

색인 노드는 문서를 분석해 검색 색인을 만드는 서버입니다. 문서가 늘어나면 노드를 추가해 처리량을 늘립니다.
화면: menu:관리[색인 노드].

[[services-nodes-status]]
=== 노드 상태

.노드 상태 표시
[cols="1,3", options="header"]
|===
| 상태 | 의미와 조치

| 정상 | 작업을 받고 있습니다.
| 과부하 | 대기 작업이 많습니다. 노드를 추가하거나 대량 업로드를 나눠서 하십시오.
| 연결 끊김 | 1분 넘게 응답이 없습니다. 노드 컨테이너가 실행 중인지 확인하십시오.
|===

[[services-nodes-add]]
=== 노드 추가

. Compose 파일에서 `lumen-indexer` 의 `replicas` 값을 늘립니다.
. `docker compose up -d` 를 실행합니다.
. 화면에서 새 노드가 *정상* 으로 표시되는지 확인합니다.

NOTE: 노드를 줄일 때는 진행 중인 작업이 끝난 뒤 줄이십시오. 처리 중이던 문서는 다른 노드에서 다시 처리됩니다.
