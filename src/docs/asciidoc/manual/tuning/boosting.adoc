[[tuning-boosting]]
== 순위 가중치

특정 조건의 문서를 결과 위쪽으로 올리거나 아래로 내립니다.
화면: menu:검색 튜닝[가중치].

.가중치 규칙 예
[cols="2,1,2", options="header"]
|===
| 조건 | 가중치 | 의도

| 지식베이스 = `공식 규정` | ×1.5 | 공식 문서를 먼저 보여 줌
| 수정일이 1년 이내 | ×1.2 | 최신 문서 우선
| 파일 이름에 `초안` 포함 | ×0.5 | 초안은 아래로
|===

가중치는 1보다 크면 순위를 올리고, 1보다 작으면 내립니다.
규칙을 저장하기 전에 btn:[미리 보기]로 대표 질문의 순위가 어떻게 바뀌는지 확인하십시오.
