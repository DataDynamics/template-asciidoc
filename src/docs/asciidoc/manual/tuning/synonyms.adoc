[[tuning-synonyms]]
== 동의어 사전

조직마다 같은 뜻을 다르게 부르는 말이 있습니다. 동의어 사전에 등록하면 어느 말로 찾아도 같은 문서가 나옵니다.
화면: menu:검색 튜닝[동의어].

.동의어 등록 예
[cols="1,2", options="header"]
|===
| 대표어 | 동의어

| 연차 | 연차휴가, 유급휴가, 월차
| 경비 | 비용, 지출
| ERP | 전사자원관리, 사내 업무 시스템
|===

NOTE: 동의어는 검색할 때 적용되므로 재색인 없이 바로 반영됩니다.

WARNING: 뜻이 넓은 말(예: `시스템`)을 동의어로 묶으면 관계없는 문서까지 나옵니다. 등록 후 <<quality-evaluation>> 으로 확인하십시오.
