== 이 매뉴얼에 대하여

IMPORTANT: {product} 은(는) 이 템플릿의 예제를 위해 만든 *가상의 제품* 입니다.
화면 이름, 설정 키, 포트, 수치는 모두 설명을 위한 예시입니다.

이 문서는 문서 템플릿으로 큰 제품 매뉴얼을 구성하는 방법을 보여 줍니다.

* 여러 장을 묶는 *부(part)* 는 `= N부` 1단계 제목으로 이 파일에 둡니다.
* *장(chapter)* 은 `manual/<부 디렉터리>/` 아래 파일 하나에 `==` 2단계 제목으로 씁니다.
* 장마다 앵커를 붙여 다른 장에서 `+<<kb-create>>+` 처럼 참조합니다.
* 제품명, 포트, URL 같은 반복 값은 헤더 속성(`+{product}+`, `+{api-port}+`)으로 한곳에서 관리합니다.
